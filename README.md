🚀 Project Objective

Financial Control aims to help users organize their finances in a practical and visual way.
With this app, users will be able to:

Record income and expenses

Categorize spending

Generate reports and performance charts

Set monthly budgets and goals

Sync data between web and mobile versions

🧩 Suggested Technologies
Frontend

Web: React / Next.js

Mobile: React Native (Expo)

UI: TailwindCSS or Chakra UI

Backend

API: Node.js (Express or NestJS)

Database: PostgreSQL / Prisma ORM

Authentication: JWT / OAuth2

Infrastructure

Hosting: Vercel (Web), Play Store / App Store (Mobile)

Database Hosting: Supabase or Railway

CI/CD: GitHub Actions
